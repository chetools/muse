# muse-html/

Static HTML pages generated by Muse, published through GitHub Pages
(source: the `gh-pages` branch of chetools/muse).

- `raise-summit-2026-vahdat-slides-transcript.html` — slide-by-slide transcript
  of "The Physics of Thought & Architecture of Intelligence" (Amin Vahdat,
  Google, RAISE Summit 2026): each slide side-by-side with the corrected
  transcript of what was said while it was shown.
- sibling-import-test-wasm.html — WASM build of the self-contained sibling-import test notebook (helper inlined); multi-file MoLab notebooks must be packaged as one file for WASM.
