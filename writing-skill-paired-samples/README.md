# Writing-skill paired samples — source of record

This directory holds the source of record for the published page
`writing-skill-paired-samples` (https://chetools.github.io/muse/writing-skill-paired-samples/).

The page is a single-file exhibit page maintained directly as HTML:
`index.html` in this directory is edited by hand and published as-is.
There is no build step, no content file, and no generator.

Before 2026-11-23 the page had no source of record anywhere in the
repository. It survived only as the published file on the `gh-pages`
branch. On 2026-11-23, during the writing-skill rewrite programme, the
source of record was established by copying the published file
byte-identically into this directory (SHA-256 of the copied file:
487e08fd03936b05c80c9a500a0ee03ff55dfcc52a17404ee9106b63fa781636,
100,931 bytes). All later edits are made to this copy; the 38 sample
passages are quoted exhibits and stand unchanged.
