AI-Assisted Grading of Video Homework: Anonymous and Verifiable

Transcribe a spoken explanation on this device, remove names and identifying words, and send the cleaned transcript for grading. The grading is done by the teacher's Muse — the teacher's AI assistant setup — which sees only the cleaned transcript. When the grade is ready you download one ZIP file for Canvas. Your audio stays on this device while it is transcribed and graded; at the end, you upload it to Canvas yourself, inside the ZIP, and the video sits on YouTube under your own account. The transcript leaves only after you confirm in step 5 that it holds nothing that identifies you, and it is sent with no name and no YouTube link.

3. Names and words to remove

One per line, or separated by commas. Every occurrence is removed from the transcript and from anything this page shows or exports. What you type here stays in this page: it is never exported, stored, or sent anywhere.

4. Transcribe

Transcription runs piece by piece, 25 s of audio at a time, on one thread. The page may appear to pause while a piece is processed; the status line and the bar update after each piece. A long recording takes many minutes. Pieces are saved on this computer as they finish, so an interrupted run resumes where it stopped when you choose the same file again.

6. Send for grading

A final submission cannot be created without a YouTube link that checks out as Unlisted or Public. The link itself is never sent with the transcript; the grading side stores only the fact that the check passed. The link is written into your submission file when you download it.

Pick a name and code you will remember; do not use your name or anything that identifies you — the page blocks a name containing a word from your removal list. The code is letters and numbers only, and a single character is enough; it is not a password, so it is shown as you type. Both are kept in this browser, so coming back to this page (or clicking the notification) retrieves your grade without typing. On a different browser, the name and code are how you retrieve it. A name can be used only once per assignment.
