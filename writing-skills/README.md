# Writing skills

## Contents

- `SKILL.md` — the writing rules: shared sentence and claim patterns, STEM structure and instructional rules, the business section, the equations section, the list of forms to avoid, and the AI-writing patterns scan. This file is the package.
- `CHECKLIST.md` — a one-page completion check keyed to the rule numbers in `SKILL.md`.
- `EXAMPLES.md` — specimen pairs at equal word counts, one version written with the rules and one written without the rules, on identical content.
- `EVIDENCE.md` — corpus sizes, test results, and limits. Rules carry no frequency counts in this package; counts sit in this file at corpus level.
- `APPENDIX.md` — patterns held out of the main rules because they rest on one corpus: two chief executive officer letter patterns, each labelled with its evidence and its conditions.

## Use with an AI assistant

Give the assistant `SKILL.md` as a standing instruction file (a skill file, a project instruction, or pasted context), and name the document type in each request: a paper, a report, a tutorial, an executive summary, a recommendation memo. Ask for a check against `CHECKLIST.md` before delivery. A revision request that names the file and the document type is sufficient: "Revise this draft under SKILL.md as a STEM report, and run the checklist."

## Use without an assistant

Draft first. Revise against `CHECKLIST.md`, one section at a time, and read `SKILL.md` at the rule a checklist item cites. Worked contrasts in `EXAMPLES.md` show each main difference in finished text.

## Scope

STEM denotes writing in science, technology, engineering, and mathematics. SI denotes the International System of Units. Shared rules and STEM rules govern by default. Business rules govern only when a business document is requested (a recommendation memo or report, an executive summary, a slide storyline); in a mixed document, technical sections follow the STEM rules and non-technical sections follow the business rules. The equations section governs any document with displayed equations. The AI-writing patterns scan applies to all writing.

## Sharing

Copy and adapt the package freely. Keep `EVIDENCE.md` with it: the limits stated there are part of the rules, and a copy without the limits overstates what the rules rest on.
