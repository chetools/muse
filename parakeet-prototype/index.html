Parakeet transcription

A general transcription page for spoken engineering English. NVIDIA Parakeet TDT 0.6B v2 (English, int8) runs entirely in this page on WebAssembly (WASM), the browser’s sandboxed code format. No server takes part in transcription. Transcripts are corrected with a chemical-engineering glossary map, described below. The page also opens on a phone, where the model load itself is the test: a phone browser gives one page far less memory than a desktop browser, and this model needs roughly 2 GB while it runs.

Privacy and network use

This page sends no telemetry and carries no analytics. The speech runtime used here is the WebAssembly build of ONNX Runtime; that build carries no telemetry (the telemetry seen earlier came from the native desktop build). A content security policy in this page’s head limits its network connections to this site and to Hugging Face. Nothing is fetched until you press “Load model”: that press downloads the model files (about 670 MB in total) from the Hugging Face repository ysdede/parakeet-tdt-0.6b-v2-onnx, and your browser caches them on this device for later visits. Your audio is read on this device only and is never uploaded. The network log at the bottom of the page lists every file this page fetches, as it happens.

Corrections

The correction map loaded in this page has 201 pairs, generated from the chemical-engineering glossary correction map (the same source the Muse transcription skill uses). Of the 203 pairs in that source, most are predicted sound-alikes, not attested errors — only 7 are attested. A confident correction replaces the misheard form outright. An uncertain one — the heard form is an ordinary English word that may have been said as itself, or the glossary lists several candidate terms — is written in the transcript as the heard form followed by every candidate, separated by slashes with no spaces, for example “viral/virial equation/virial coefficient”, so nothing is silently chosen. One exception: where the word next to the mishearing is the last word (or the first word) of exactly one candidate, the context settles the choice — “viral coefficient” becomes “virial coefficient” — and the list below the transcript marks that correction as chosen by context and names the cue word. After every transcription, the page lists each correction it applied and marks the uncertain ones, so any correction can be checked against the recording.

Autosave

While a transcript exists, this page saves it inside the browser after every transcribed piece and every 15 s, so a crash loses at most the piece in progress. On a laptop in desktop Chrome, you can also choose a file on disk and the page writes the same text to that file on the same schedule.
