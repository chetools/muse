Parakeet in the browser — prototype

NVIDIA Parakeet TDT 0.6B v2 (English, int8) running entirely in this page on WebAssembly (WASM), the browser’s sandboxed code format. No server takes part in transcription.

Purpose: measure, on a desktop Chrome browser, whether this model is fast and accurate enough in a static page to be worth using in place of the smaller Whisper model in the Bernoulli explanation app.

Privacy and network use

This page sends no telemetry and carries no analytics. The speech runtime used here is the WebAssembly build of ONNX Runtime; that build carries no telemetry (the telemetry seen earlier came from the native desktop build). A content security policy in this page’s head limits its network connections to this site and to Hugging Face. Nothing is fetched until you press “Load model”: that press downloads the model files (about 670 MB in total) from the Hugging Face repository ysdede/parakeet-tdt-0.6b-v2-onnx, and your browser caches them on this device for later visits. Your audio file is read on this device only and is never uploaded. The network log at the bottom of the page lists every file this page fetches, as it happens.
