Slate balance and furnace duty model

The model is computed in Python. The precomputed default run is displayed on load; a live run replaces the displayed values. Symbols: the crude oil feed rate is denoted feed rate (in kilogram per hour, kg/h); each product cut yield is in mass per cent of the crude feed; the furnace outlet temperature is in degree Celsius; the mean specific heat capacity of the desalted crude, denoted cp, is in kilojoule per kilogram per kelvin (kJ/(kg K)). The default value of cp is 2.2 kJ/(kg K), an assumed value stated as an assumption in the Theory panel.

Inputs differ from the displayed run. Press Run model to recompute.
