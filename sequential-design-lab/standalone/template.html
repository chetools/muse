Sequential Design for Global Models

Comparison of experiment-selection strategies for a global predictive model under a small budget. A seeded true model generates data with noise; a Gaussian process is fitted after each batch; sequential batches are selected by the chosen strategy. All calculations are performed in Python (Pyodide). If the Python runtime cannot load, an explicit error is shown and no calculation is performed.

Proposed batch (editable)

Points proposed by the selected strategy. Values are scaled inputs in [0, 1] and may be edited before execution; constraint violations are rejected before execution with the constraint named. Additional rows may be added manually up to the remaining budget.

Executed runs

Rows are listed in the randomised order in which the runs were executed. Columns y1 to ym hold the noisy observed values of the responses for each run; a dash denotes a value removed under the missing-response option.
