# Theory

## Scope and symbols

The simulation compares methods for selecting experiments when the objective is a global predictive model: a model whose prediction error, averaged over the whole region in which predictions will be required, is to be made as small as possible under a small experiment budget. The alternative objective of locating a single best operating point is represented only by one deliberately mismatched strategy, described under Alternative selection strategies, so that the cost of using an optimisation criterion for a prediction objective can be observed directly.

The following symbols are used throughout this panel and in the figure labels and captions of the App panel. The symbol $d$ denotes the number of input variables (a count, dimensionless). The symbol $n$ denotes the total number of experiments in the session budget (a count). The symbol $m$ denotes the number of responses measured on each experiment (a count). The symbol $x_i$ denotes the $i$-th scaled input variable, dimensionless, with $0 \le x_i \le 1$. The symbol $\mathbf{x}$ denotes the vector of all $d$ scaled inputs at one experiment. The symbol $j$ denotes a response index, running from $1$ to $m$, and the symbol $i$ denotes a variable index, running from $1$ to $d$. The symbol $y_j$ denotes the observed value of response $j$ at one experiment, and $f_j(\mathbf{x})$ denotes the noiseless true value of response $j$ at input $\mathbf{x}$. All responses are carried on a standardised scale, defined under True model class, on which the noiseless response of each response has variance $1$ over the region; response values, errors, and standard deviations are therefore in standardised response units, and variances are in squared standardised response units. A batch denotes a set of experiments proposed together, executed together, and only then used in refitting; a round denotes one execution of a batch, with round 1 denoting the initial design batch. The strategy tournament display uses a shifted count in which the state after the initial batch is round 0; the convention in force is stated at each display. A point described as normalised (normalized in American spelling) has been divided by a stated reference quantity, and the divisor is stated at every use; a normalised quantity is dimensionless.

## Scenario and design space

A scenario is fixed by the seed, the variable count $d$, the response count $m$, the budget $n$, the batch size, the importance weights, and the advanced settings for the fitted model, the noise model, categorical variables, and constraints. The seed is an integer from which every random element of the session is derived: the drawn true model, the candidate pool, the initial design, the noise added to each observation, and the randomised execution order within each batch. Repeating a session with the same seed and the same settings reproduces identical data.

Each physical variable is represented by its scaled form: the physical value minus its lower bound, divided by the difference between its upper and lower bounds, so that every variable lies in the unit interval and is dimensionless. The design space is the unit hypercube of dimension $d$, possibly reduced by the coupled constraints described under Constraints and feasibility. Two fixed point sets are generated at the start of every session. The reference set is a set of 5,000 points in the design space, drawn as a scrambled Sobol sequence {{cite:sobol-1967}} with a fixed seed (4,242) that does not depend on the session seed; the reference set represents the region of use under a uniform operating distribution, meaning that equal volumes of the region carry equal weight. The candidate pool is a set of 20,000 feasible points, drawn as a scrambled Sobol sequence under the session seed and passed through the feasibility filter of Constraints and feasibility; sequential strategies select batch points from the candidate pool, with continuous positions in the pool, not on a grid.

The first $n_{\mathrm{cat}}$ variables, where $n_{\mathrm{cat}}$ denotes the number of categorical variables set in the scenario (zero by default), are categorical: each takes one of $L$ unordered levels, where $L$ denotes the number of levels (2, 3, or 4). A categorical variable is recorded by its level index $\nu_i$, an integer from $0$ to $L - 1$ obtained as the integer part of $L x_i$, clipped to the range. Design and candidate points are snapped to level centres, meaning that a point with level index $\nu_i$ carries the scaled coordinate $(\nu_i + \tfrac{1}{2}) / L$.

## True model class

The true model is a function drawn at session creation by the seeded generator. Its functional form is fixed by the class described in this section; only its coefficients, its active variables, and its basis choices are drawn, and they are hidden during play. The revealed true model at the end of a session is the drawn function itself, displayed as a typeset equation whose template is given in this section.

For response $j$, the unstandardised true response $T_j(\mathbf{x})$, in arbitrary generator units, is a sparse sum of three kinds of term:

$$T_j(\mathbf{x}) = \sum_{i \in A_j} a_{ji}\, g_{ji}(x_i) + \sum_{(i,k) \in P_j} b_{jik}\, h_{jik}(x_i, x_k) + c_j \cdot 8 \left(x_p - \tfrac{1}{2}\right) \left(x_q - \tfrac{1}{2}\right) \left(x_r - \tfrac{1}{2}\right)$$

The symbol $A_j$ denotes the active set of response $j$: the set of variable indices that affect response $j$. Variables outside $A_j$ are inert for response $j$, meaning that changing them does not change $f_j$. The symbol $a_{ji}$ denotes the main-effect coefficient of variable $i$ in response $j$, drawn from a normal distribution with mean $0$ and standard deviation $1$. The symbol $g_{ji}$ denotes a nonlinear basis function of one variable, drawn uniformly from the following five forms, in which $u$ denotes the variable value in $[0, 1]$: $\sin(2\pi u)$; $4(u - \tfrac{1}{2})^2 - \tfrac{1}{3}$; $\exp(1.5(u - \tfrac{1}{2}))$; $(1 + \exp(-8(u - \tfrac{1}{2})))^{-1}$, the logistic form; and $1 - 2|u - \tfrac{1}{2}|$, the tent form. The symbol $P_j$ denotes a set of at most three variable pairs drawn from the active continuous variables of response $j$; $b_{jik}$ denotes the coefficient of pair $(i, k)$, drawn from a normal distribution with mean $0$ and standard deviation $0.8$; and $h_{jik}$ denotes the pair basis, drawn with equal probability from the product form $4(x_i - \tfrac{1}{2})(x_k - \tfrac{1}{2})$ and the product-of-sines form $\sin(2\pi x_i)\sin(2\pi x_k)$. The symbol $c_j$ denotes the coefficient of at most one three-variable product, over the first three active continuous variables, indexed $p$, $q$, $r$; $c_j$ is drawn from a normal distribution with mean $0$ and standard deviation $0.5$, and the factor $8$ makes the product range over $[-1, 1]$.

The number of active variables, denoted $n_{\mathrm{act}}$, is either set by the instructor control or drawn uniformly from the integers between $\max(1, \lfloor d/3 \rfloor)$ and $d$. Of the active variables, a shared subset of size $\max(1, \mathrm{round}(0.6\, n_{\mathrm{act}}))$ is common to all responses; the remaining active variables of each response are drawn from the variables outside the shared subset. Correlation between responses therefore arises through shared active variables, not through correlated noise {{cite:kennedy-ohagan-2001}}.

A categorical variable in the active set enters differently. Instead of a basis term it contributes a level offset: a value $o_{j i \nu}$, drawn from a normal distribution with mean $0$ and standard deviation $1$ and then centred so that its mean over the $L$ levels is $0$, added when variable $i$ is at level $\nu$. In addition, for one continuous active partner variable $u$ it contributes a level-specific slope term $2\, \gamma_{j i \nu}\, (x_u - \tfrac{1}{2})$, where $\gamma_{j i \nu}$ denotes the slope coefficient of variable $i$ at level $\nu$ in response $j$, a per-level slope coefficient drawn from a normal distribution with mean $0$ and standard deviation $0.6$.

The standardised true response $f_j(\mathbf{x})$, the quantity the fitted models attempt to predict and the quantity against which all errors are computed, is

$$f_j(\mathbf{x}) = \frac{T_j(\mathbf{x}) - \bar{f}_j}{s_j}$$

The symbol $\bar{f}_j$ denotes the mean of $T_j$ over a fixed grid of 4,096 scrambled Sobol points in the design space, and $s_j$ denotes the standard deviation of $T_j$ over the same grid. Division by $s_j$ gives $f_j$ unit variance over the region, so that a prediction error of $0.5$ has the same meaning for every response: half the standard deviation of the true response itself.

## Noise models and the signal-to-noise ratio

The observed response is the noiseless response plus measurement noise: $y_j = f_j(\mathbf{x}) + \varepsilon_j$, where $\varepsilon_j$ denotes the noise in observation $j$, in standardised response units. The signal-to-noise ratio of response $j$, denoted $\mathrm{SNR}_j$, is defined as a variance ratio:

$$\mathrm{SNR}_j = \frac{\mathrm{variance\ of\ } f_j}{\mathrm{variance\ of\ } \varepsilon_j}$$

The signal-to-noise ratio is dimensionless. Because $f_j$ is standardised to unit variance, the base noise standard deviation of response $j$ is $1 / \sqrt{\mathrm{SNR}_j}$; at the default signal-to-noise ratio of $4$, the noise standard deviation is $0.5$ standardised response units. One signal-to-noise ratio applies to all responses by default; the advanced per-response setting supplies a separate value per response.

Four noise forms are implemented, selected per scenario. (1) Gaussian noise with constant variance: $\varepsilon_j$ is drawn from a normal distribution with mean $0$ and the base standard deviation, independently at every point. (2) Gaussian noise with input-dependent variance: the standard deviation is multiplied by a factor $0.4 + x_1$, then the factor is divided by its root mean square over the points in question, so that the average noise variance over those points still equals $1 / \mathrm{SNR}_j$; points at large $x_1$ are noisier than points at small $x_1$. (3) Multiplicative noise: the multiplying factor is $0.25 + |f_j(\mathbf{x})|$, rescaled by the same root-mean-square procedure, so noise grows with the magnitude of the response. (4) Gaussian noise with outliers: the constant-variance Gaussian draw is made as in form (1), and then, independently for each observed value with probability $0.05$, an additional draw from a normal distribution with standard deviation four times the base standard deviation is added. An advanced option additionally deletes each response value independently with a stated probability, producing a missing value; a run with one missing response is still used for its remaining responses, as described under Multiple responses and importance weights.

## Initial design

The initial batch is constructed before any model can be fitted, so it is chosen by coverage of the design space alone, following the design of computer experiments tradition {{cite:sacks-etal-1989}} {{cite:santner-etal-2018}}.

A Latin hypercube design of size $n_0$, where $n_0$ denotes a count of design points, divides the range of every variable into $n_0$ equal strata and places exactly one point in each stratum of each variable {{cite:mckay-etal-1979}}. Operationally: for each variable independently, the interval $[0, 1]$ is cut into $n_0$ equal bins, one point is placed in each bin at a uniform random position within the bin, and the bin assignments of the different variables are combined by independent random permutations. Every one-dimensional projection of the design is therefore evenly spread, whatever the values of the other variables. The design used here is generated by the Latin hypercube sampler of the SciPy quasi-Monte Carlo module and then improved as follows.

The maximum projection criterion, denoted $\Phi$, selects among Latin hypercube designs the design that remains well separated in every low-dimensional projection {{cite:joseph-etal-2015}}. For a design with points indexed by $s$ and $t$, $\Phi$ is

$$\Phi = \left[ \frac{1}{\binom{n_0}{2}} \sum_{s < t} \prod_{i=1}^{d} \frac{1}{(x_{si} - x_{ti})^2} \right]$$

The symbol $x_{si}$ denotes the value of variable $i$ at design point $s$, and $\binom{n_0}{2}$ denotes the number of unordered point pairs. A pair of points that nearly coincides in any one coordinate makes the corresponding factor large, so a small $\Phi$ requires separation in all coordinates simultaneously, and hence in every projection onto a subset of variables; distance-based design criteria of this family originate with maximin distance designs {{cite:johnson-etal-1990}}. The published criterion raises the bracketed mean to the power $1/(2d)$; a positive power is a monotone transformation and does not change which design minimises the criterion, so the implementation minimises the unraised mean directly. The symbol $\Phi$ denotes this criterion; the standard normal distribution function used under Alternative selection strategies is written $\Phi_Z$ and is unrelated. Improvement proceeds by coordinate swaps: two points are chosen at random, their values in one continuous variable are exchanged (an exchange that preserves the Latin hypercube property, since each stratum still holds exactly one point), the swap is kept if it reduces $\Phi$ and does not violate a constraint, and the process repeats for a fixed number of steps (300 in the initial design).

The initial batch is governed by the size parameter $s_0$, which follows the rule $s_0 = \min(\max(\mathrm{round}(0.4\, n), 2(d + 3)), \mathrm{round}(0.6\, n), n - b)$, where $b$ denotes the batch size of the scenario; the term $d + 3$ is the number of fitted parameters of one Gaussian process model (one length scale per variable, a signal standard deviation, a noise standard deviation, and a mean), so the rule keeps the initial batch at or above twice the parameter count while never consuming more than 60 percent of the budget. The initial batch itself consists of $s_0 - 2$ maximum projection Latin hypercube points plus the centre point of the design space (all continuous variables at $0.5$, categorical variables at their central level) executed three times, giving $s_0 + 1$ runs in total; at the defaults $n = 48$, $d = 10$, the initial batch is 27 runs. The three centre runs are replicates: identical input settings with independent noise draws. Their spread estimates the noise variance directly, before any model is fitted, and their mean checks for drift when compared with later rounds. Execution order within the batch is randomised, so that any slow drift of the experimental system is not confounded with position in the design.

## Fitted model: Gaussian process regression

One model is fitted per response. The default model is a Gaussian process: a probability distribution over functions, specified by a mean function and a covariance function, such that the values of the function at any finite set of points follow a joint normal distribution {{cite:rasmussen-williams-2006}}. The mean function is constant, equal to the mean of the observed values of that response. The covariance function used by default is the Matérn covariance with smoothness parameter five halves {{cite:matern-1960}} {{cite:stein-1999}}. For two points $\mathbf{x}$ and $\mathbf{x}'$, with $r$ denoting the scaled distance between them, defined after the equation,

$$k(\mathbf{x}, \mathbf{x}') = \sigma_f^2 \left(1 + \sqrt{5}\, r + \tfrac{5}{3} r^2\right) \exp(-\sqrt{5}\, r), \qquad r = \sqrt{\sum_{i=1}^{d} \frac{(x_i - x_i')^2}{\ell_i^2}}$$

The symbol $\sigma_f^2$ denotes the signal variance, in squared standardised response units: the variance of the function itself. The symbol $\ell_i$ denotes the length scale of variable $i$, dimensionless: roughly the distance in scaled variable $i$, other variables held fixed, over which the function changes appreciably. A short length scale marks a variable to which the response is sensitive; a long length scale marks a variable with little effect. The smoothness parameter five halves gives sample functions that are twice differentiable, a middle ground between the infinitely smooth squared exponential covariance and rougher Matérn forms; the smoothness of the Matérn class and its consequences for interpolation are treated by Stein {{cite:stein-1999}}. Separate length scales per variable are termed automatic relevance determination {{cite:rasmussen-williams-2006}} {{cite:santner-etal-2018}}: relevance is determined automatically because a variable the data show to be inert receives a long fitted length scale and is effectively switched off. The observation noise variance is denoted $\sigma_n^2$, in squared standardised response units; the covariance of two observed values is the function covariance plus $\sigma_n^2$ when the two observations are the same point, and the function covariance otherwise.

Fitting proceeds in the following steps. The observed values of the response are standardised by subtracting their mean and dividing by their standard deviation. The hyperparameters — the $d$ length scales, the signal standard deviation $\sigma_f$, and the noise standard deviation $\sigma_n$, all fitted on the logarithmic scale within stated bounds — are chosen to maximise the marginal likelihood, the probability of the observed values integrated over all functions consistent with the covariance, by a bounded quasi-Newton optimisation (L-BFGS-B) from two starting points when the full fit is used. With the fitted hyperparameters, the covariance matrix $K$ of the training points, where $K$ denotes the matrix with entries $k(\mathbf{x}_s, \mathbf{x}_t) + \sigma_n^2$ on the diagonal, is factorised once by a Cholesky factorisation. The predictive mean at a new point is the constant mean plus a weighted combination of the observed values, with weights obtained from the covariance between the new point and the training points and the factorised $K$; the predictive variance at a new point is $\sigma_f^2$ minus the reduction in variance produced by the training points, computed from the same factorisation. Both quantities are returned in standardised response units (variance in squared units).

Three alternative fitted models are available as advanced options. A single shared length scale for all variables (the isotropic model) cannot switch variables off individually. An additive model replaces the covariance by the average of $d$ one-dimensional Matérn covariances, one per variable, and can represent main effects but no interactions between variables. A quadratic polynomial model fits, by a ridge regression with a small penalty, the features $1$, $x_i$, $x_i^2$, and $x_i x_k$ for all pairs; its predictive variance is the residual variance multiplied by one plus a leverage term, and it is included so that the effect of a rigid model class can be observed.

For a categorical variable, two covariance treatments are available {{cite:rasmussen-williams-2006}}. Under the correct categorical covariance, the scaled difference in that coordinate is replaced by a pseudo-distance: $0$ divided by the length scale when the two points are at the same level, and $1$ divided by the length scale when they are at different levels, so that points at the same level are fully similar in that coordinate and points at different levels are dissimilar by a fixed amount. Under naive numeric coding, the level-centre coordinates $(\nu_i + \tfrac{1}{2}) / L$ are treated as ordinary numbers, imposing an ordering and equal spacings on levels that the scenario does not contain; this option is a deliberate misspecification, available so that its cost can be measured.

## Quantities computed after each batch

After every batch is executed, each response model is refitted on all runs so far, and the following quantities are computed and recorded. Each is defined by the exact procedure used.

Predictive mean and predictive variance at a point are the output of the fitted model at that point, as defined under Fitted model. The predictive standard deviation at a point is the square root of its predictive variance.

Leave-one-out error is computed by the following procedure, stated for one response with $n_{\mathrm{done}}$ observed runs, where $n_{\mathrm{done}}$ denotes the number of experiments completed so far. For each run $s$ in turn: remove run $s$ from the training set; fit the model to the remaining $n_{\mathrm{done}} - 1$ runs; predict the response at the input of run $s$; record the difference between the observed value and that prediction. The leave-one-out error is the root mean squared value of those differences: the square root of the mean of their squares, in standardised response units. It estimates prediction error at a new point without using the hidden truth and without reserving any runs as a separate test set. For a Gaussian process the $n_{\mathrm{done}}$ refits are not performed literally: exact identities give the same leave-one-out predictions from the single fitted model, using the diagonal entries of the inverse of the covariance matrix $K$ — the leave-one-out prediction for run $s$ is its observed standardised value minus the $s$-th entry of $K^{-1}$ times the standardised observation vector, divided by the $s$-th diagonal entry of $K^{-1}$, and the leave-one-out variance is the reciprocal of that diagonal entry {{cite:rasmussen-williams-2006}}. The same leave-one-out predictions give the interval coverage: the fraction of runs whose observed value falls inside the leave-one-out prediction interval, defined as the leave-one-out mean plus or minus $1.645$ leave-one-out standard deviations, the interval that should contain about 90 percent of observations if the model and its uncertainties are accurate.

The integrated predictive variance of response $j$, denoted $V_j$, is the average of the predictive variance of the model for response $j$ over the reference set: the predictive variance is computed at each of the 5,000 reference points and the 5,000 values are averaged, giving a quantity in squared standardised response units. The root mean predictive variance of response $j$ is the square root of $V_j$, in standardised response units; it is the typical predictive standard deviation over the whole region, and its weighted form appears in Fig. 1 of the App panel as the series labelled Integrated std, where std denotes standard deviation: the value plotted at each round is $\sqrt{\sum_j w_j V_j}$, a weighted root mean over responses of the integrated predictive variances, with $w_j$ the response weight defined under Multiple responses and importance weights.

The initial-batch reference value $V_{j0}$ is the integrated predictive variance of response $j$ computed from the model fitted to the initial batch — that is, $V_j$ evaluated once, immediately after round 1, and then held fixed for the rest of the session. $V_{j0}$ is the normalising divisor for response $j$: any quantity normalised by $V_{j0}$ is expressed as a fraction (or a multiple) of the uncertainty the model had after the initial design, before any sequential selection took place. A normalised integrated variance of $0.25$ therefore means that the current average predictive variance is one quarter of its initial value.

The two relevance displays of Fig. 2 are constructed as follows. The fitted relevance of variable $i$ is the inverse of the fitted length scale of variable $i$ for the first response, normalised (divided by the sum of the inverse length scales over all variables, so the shares sum to 1). The true importance of variable $i$ for response $j$ is computed from the drawn terms of the true model of response $j$: a continuous main term contributes the absolute value of its coefficient to its variable; a categorical main term contributes the sum over levels of the absolute values of its level offsets to its variable; a pair term contributes half of the absolute value of its coefficient to each of its two variables; a categorical pair term contributes half of the sum over levels of the absolute values of its slope coefficients to each of the categorical variable and its continuous partner; and a three-variable term contributes one third of the absolute value of its coefficient to each of its three variables. The contributions are then normalised (divided by their sum over variables), giving dimensionless shares. The two constructions are different quantities — a fitted-model property and a property of the drawn truth — and are plotted together only to show whether the fitted model has identified the influential variables.

## Scoring against the truth

Scoring compares the fitted models with the hidden noiseless truth, which the simulation knows exactly. Scores are computed after every round but are hidden during play unless the instructor toggle is on; they are revealed at completion.

The per-response true error $R_j$, in standardised response units, is computed as follows: the model for response $j$ predicts at each of the 5,000 reference points; each prediction is subtracted from the noiseless true value $f_j$ at the same point; the squared differences are averaged over the 5,000 points; the square root of that average is $R_j$, the root mean squared error of the model for response $j$ over the region. The combined true score $S$, dimensionless, combines the responses with their weights and with the initial-batch normalisation:

$$S = \sqrt{\sum_{j=1}^{m} w_j \frac{R_j^2}{V_{j0}}}$$

A score of $1$ means that, in the weighted normalised sense, the models are exactly as inaccurate as the initial-batch models were uncertain; smaller is better, and the score can fall well below $1$ as sequential batches reduce both error and variance. This scoring is an instance of the integrated mean squared error criterion for computer experiments {{cite:sacks-etal-1989}}.

The calibration ratio of response $j$ is $R_j$ divided by the root mean predictive variance of response $j$, that is $R_j / \sqrt{V_j}$ with $V_j$ the current integrated predictive variance. Both numerator and denominator are in standardised response units, so the ratio is dimensionless. A ratio near $1$ indicates agreement between the realised error and the model's own stated uncertainty, in the sense of the calibration assessment of computer models {{cite:kennedy-ohagan-2001}}: a ratio well above $1$ means the model is overconfident (its errors are larger than its stated uncertainty), and a ratio well below $1$ means it is underconfident. The calibration ratio complements the interval coverage defined under Quantities computed after each batch, which measures the same agreement on the observed runs rather than on the truth.

## Sequential selection by integrated variance reduction

The integrated variance reduction strategy selects each batch to reduce the integrated predictive variance of the weighted combination of responses as much as possible. The strategy belongs to the active learning family for statistical models {{cite:cohn-etal-1996}} and to Bayesian experimental design, in which a design is chosen by the expected information or uncertainty reduction it produces {{cite:chaloner-verdinelli-1995}}.

The gain of a candidate point is derived as follows. If a candidate point $\mathbf{x}$ were executed for response $j$, the predictive variance at any reference point $\mathbf{z}$ would fall by an amount determined by the posterior covariance between $\mathbf{z}$ and $\mathbf{x}$: the reduction is $\mathrm{cov}_j(\mathbf{z}, \mathbf{x})^2$ divided by the variance of the new observation, which is the predictive variance at $\mathbf{x}$ plus the noise variance $\sigma_{nj}^2$, where $\mathrm{cov}_j(\mathbf{z}, \mathbf{x})$ denotes the posterior covariance of the current model for response $j$ between the two points, in squared standardised response units. Averaging that reduction over the reference set and normalising by $V_{j0}$ gives the gain $G_j(\mathbf{x})$ of the candidate for response $j$:

$$G_j(\mathbf{x}) = \frac{1}{V_{j0}} \int \frac{\mathrm{cov}_j(\mathbf{z}, \mathbf{x})^2}{\mathrm{var}_j(\mathbf{x}) + \sigma_{nj}^2} \, d\mathbf{z}$$

The integral is over the design space with the uniform operating distribution, and is evaluated in practice as the average over reference points, as specified in the approximations below. $\mathrm{var}_j(\mathbf{x})$ denotes the predictive variance at the candidate. $G_j$ is dimensionless: the fraction of the initial integrated uncertainty of response $j$ that one observation at $\mathbf{x}$ is expected to remove. A candidate scores highly when it is uncertain itself and when it is strongly correlated with many reference points, that is, when learning its value informs a large part of the region.

Batch construction is greedy and proceeds in the following steps. (1) The candidate pool of 20,000 feasible points is scored by total predictive variance, the weighted sum over responses of predictive variance, and the 3,000 highest-variance feasible candidates are retained (approximation 1, stated in full below). (2) The gain of every retained candidate is computed under the combined criterion $\sum_j w_j G_j(\mathbf{x})$ for the first part of the batch, where $w_j$ is the weight of response $j$. (3) The candidate with the largest gain is selected. (4) The selected point is provisionally appended to every response model at its predicted mean — the Kriging believer update {{cite:ginsbourger-etal-2010}} — meaning that the covariance factorisation is recomputed as if the point had been observed with value equal to the current prediction, hyperparameters held fixed; predictive variances near the pending point fall, so the next selection is pushed away from near-duplicates of points already in the batch. (5) Steps (2) to (4) repeat until the batch is full, with one exception: the final quarter of the batch, rounded up to a whole number of points, is selected by the gain for the worst-served response alone. The worst-served response is the response whose current integrated predictive variance, divided by its own $V_{j0}$, is largest — the response that has made the least relative progress since the initial batch. This reservation prevents the weighted criterion from abandoning a low-weight response whose variance is difficult to reduce. No continuous optimisation of candidate positions is performed; candidates keep the positions drawn in the pool.

Two implementation approximations are used in scoring candidates, and both are stated here because they are part of the method as implemented. Approximation 1 (pool screening): as in step (1), only the 3,000 retained candidates receive a gain evaluation; a candidate with low total predictive variance cannot have a large gain, because its numerator covariances are bounded by its own variance, so screening by variance removes only candidates that could not have been selected. Approximation 2 (reference subset): the integral in $G_j$ is estimated on a fixed stratified subset of 1,000 reference points, formed by taking every fifth point of the 5,000-point reference set; this is an unbiased Monte Carlo estimate of the same integral, in the sense that its expectation over the subset choice equals the full-set value, and the subset is fixed across candidates and rounds so that comparisons are not polluted by subset noise. All reported quantities — integrated predictive variances, true errors, scores, and calibration ratios — always use the full 5,000-point reference set, never the subset.

## Alternative selection strategies

Four further strategies are implemented, so that their learning curves can be compared on identical sessions.

Random sampling draws each batch uniformly at random from the feasible region, by rejection of infeasible draws. It uses neither coverage criteria nor the fitted model, and provides the baseline against which structure is measured.

The one-shot Latin hypercube strategy continues the initial design method: every batch is a fresh maximum projection Latin hypercube design of batch size {{cite:mckay-etal-1979}} {{cite:joseph-etal-2015}}, constructed without reference to any observed response. It represents the classical single-stage design approach, in which all experiments are specified by coverage before modelling begins, applied here in successive batches because the interface is batched.

Maximum predictive variance selects, greedily with the same Kriging believer batch construction, the candidates with the largest weighted predictive variance, normalised per response by $V_{j0}$: the score of a candidate is $\sum_j w_j \, \mathrm{var}_j(\mathbf{x}) / V_{j0}$. It differs from integrated variance reduction in ignoring correlation with the rest of the region: a point can have high variance while informing only its immediate neighbourhood, typically near the boundary, and this strategy repeatedly selects such points.

Expected improvement is an optimisation criterion {{cite:jones-etal-1998}}, included deliberately as a mismatch. For response $j$ it scores a candidate by the expected amount by which a new observation would exceed the best value observed so far:

$$\mathrm{EI}_j(\mathbf{x}) = \left(\mu_j(\mathbf{x}) - y_j^{+}\right) \Phi_Z\!\left(\frac{\mu_j(\mathbf{x}) - y_j^{+}}{\varsigma_j(\mathbf{x})}\right) + \varsigma_j(\mathbf{x}) \, \phi_Z\!\left(\frac{\mu_j(\mathbf{x}) - y_j^{+}}{\varsigma_j(\mathbf{x})}\right)$$

The symbol $\mu_j(\mathbf{x})$ denotes the predictive mean at the candidate; $y_j^{+}$ denotes the largest observed value of response $j$ so far, so the criterion treats a larger response as better; $\varsigma_j(\mathbf{x})$ denotes the predictive standard deviation at the candidate; and $\Phi_Z$ and $\phi_Z$ denote the cumulative distribution function and the probability density function of the standard normal distribution. The first term rewards candidates predicted to be good, and the second rewards candidates that are uncertain; the criterion thereby balances exploitation of good regions against exploration, for the purpose of finding a maximum. The implementation combines responses as the weighted sum of $\mathrm{EI}_j$ divided by the standard deviation of the observed values of response $j$. For a global predictive objective the criterion is mismatched by construction: once a promising region is found, expected improvement concentrates the remaining budget there, because points elsewhere offer little chance of exceeding the best observed value, even when the model elsewhere is poor. Its learning curve for the true score is therefore expected to fall more slowly than the curves of the prediction-oriented criteria, and the comparison is the lesson of the simulation.

## Multiple responses and importance weights

Each response carries an importance percentage, set in the scenario, and the percentages must sum to 100; the interface rejects a session whose percentages do not sum to 100. The weight of response $j$, denoted $w_j$, is its percentage divided by 100, so the weights sum to 1. Weights enter in exactly three places: the combined gain of Sequential selection by integrated variance reduction, the combined true score $S$, and the weighted combinations plotted in Fig. 1. Before any weighting, each response's gain and error are normalised by that response's own $V_{j0}$, so a response with a naturally large scale cannot dominate the combination merely through its units or its initial uncertainty.

One model is fitted per response, independently: the responses share the same executed design points, but no parameters, so a response with a short length scale on a variable and a response insensitive to that variable are represented without compromise. If a response value is missing for a run (only under the advanced missing-value option), that run is omitted from the fit of that response only; a response with fewer than four observed values receives no model and contributes nothing to selection scores until enough values exist.

An optional target accuracy per response, in standardised response units, may be supplied. It is used only for termination reporting: at completion, the report states for each response whether its true error $R_j$ is at or below its target. It does not enter selection or scoring.

## Constraints and feasibility

Independent bounds always apply: every scaled variable must lie in $[0, 1]$, and a point outside its bounds is infeasible. Two coupled constraints are selectable. The linear sum constraint requires the mean of the first four scaled variables (or of all variables, when fewer than four exist) to be at most $0.72$. The circular forbidden region excludes every point with $(x_1 - 0.5)^2 + (x_2 - 0.5)^2 < 0.18^2$, a disc of radius $0.18$ about the centre of the first two scaled coordinates, in dimensionless scaled units.

A point that violates a bound or a selected coupled constraint is rejected before execution, and the rejection message names the violated constraint. Rejection applies to manually entered points and to edited strategy proposals. The candidate pool, the random strategy, and the Latin hypercube batches are constructed by feasibility filtering: draws are generated until enough feasible points are collected, Latin hypercube improvement swaps that would create an infeasible point are reverted, and categorical coordinates are snapped to level centres before feasibility is tested.

## Strategy tournament

The tournament compares the five strategies — random, one-shot Latin hypercube, maximum predictive variance, integrated variance reduction, and expected improvement — under identical conditions, as an instructor panel. For each repetition, every strategy is run on a session with the same scenario settings and the same seed (the scenario seed plus 1,000 times the repetition index), so all strategies face the same drawn true model and the same noise sequence structure within a repetition; only the selected points differ. Tournament sessions use a reduced candidate pool and reference set of 2,000 points each and the fast fit (a single optimisation starting point and fewer iterations), a reduction stated here because tournament curves are therefore indicative rather than identical to session curves. After each round of each run, the true score $S$ is recorded; the plotted curve for a strategy is the median of its recorded scores across repetitions at each round, where the median of a set of numbers is the middle value when the numbers are placed in increasing order (the average of the two middle values for an even count). The horizontal axis is the round index, with round 0 denoting the state after the initial batch (in the session displays of the App panel, the initial batch itself is counted as round 1). A progress indicator advances as repetition–strategy jobs complete, one job being one full tournament run of one strategy in one repetition.

## Computation

All calculations are performed in Python with NumPy vectorisation, in the browser through the Pyodide runtime. Candidate scoring is chunked so that covariance matrices between blocks of candidates and reference points are formed one block at a time, and the kernel evaluations use the expansion of the squared scaled distance into a sum of squares minus twice an inner product, so that the dominant cost is one matrix product per block. No Rust or WebGPU implementation is used: Gaussian process calculations require 64-bit floating-point arithmetic, which the WebGPU shading language does not provide, and measured NumPy timings at the default scale (an integrated variance reduction round of about 6 seconds on the reference hardware, against a target of approximately 10 seconds) meet the interaction requirement stated in the design specification. If the Python runtime cannot load, the page shows an explicit error; no calculation is performed by any other means.
