# Notebook to paper comparison

A single-file exhibit page: research-notebook notes on carbon dioxide
absorption into aqueous monoethanolamine, set beside the report transformed
from them under the writing skill, with framing sections that record how the
transformation and the organisation were done, how the writing was improved,
what the transformation could not settle, and how the skill was created.

## Maintenance

The page is maintained directly as HTML in the single file `index.html`
in this directory. There is no build step: the file in this directory is
the file published at
https://chetools.github.io/muse/notebook-to-paper-comparison/ .

The two columns (the notebook notes and the transformed report) are quoted
exhibits and stand unchanged; edits are confined to the framing prose and
the page apparatus.
