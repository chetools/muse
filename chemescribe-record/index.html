Technical details

Recogniser

The recogniser is NVIDIA Parakeet TDT 0.6B v2 (English, int8). Pressing “Load model” downloads its files (about 670 MB in total) from the Hugging Face repository ysdede/parakeet-tdt-0.6b-v2-onnx; the browser caches them on this device for later visits. Your audio is read on this device only and is never uploaded.

Runtime

The recogniser runs on WebAssembly (WASM), the browser’s sandboxed code format, through parakeet.js 1.4.4 and ONNX Runtime Web 1.24.1, both vendored on this site. The backend is the CPU on one thread: multi-threaded WASM needs an extra browser isolation mode that this site cannot use. While it runs, the model needs roughly 2 GB of memory; a phone browser gives one page far less memory than a desktop browser, so on a phone the model load itself is the test.

Privacy and network audit

This page sends no telemetry and carries no analytics. The speech runtime is the WebAssembly build of ONNX Runtime, and that build carries no telemetry (the telemetry observed earlier came from the native desktop build). A content security policy in this page’s head limits its network connections to this site and to Hugging Face. Before publication the vendored files were string-searched for telemetry and analytics endpoints — among them mobile.events.data.microsoft.com and OneCollector — and none were found; headless test runs recorded requests to this site only on load, and to this site and Hugging Face after “Load model” was pressed. Nothing is fetched until you press “Load model”.

No correction data

This page loads no correction data: no glossary, no correction pairs, no dictionary. The transcript it shows is the recogniser’s raw output, uncorrected. Correction is a separate step, done in Muse with the ChemEScribe skill and the prompt above.
