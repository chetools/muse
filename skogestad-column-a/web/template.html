Skogestad Column A: control configurations and transfer matrices

A binary distillation column with N trays (default N = 5), a reboiler and a total condenser, following Skogestad's Column A model. The page simulates the nonlinear column, linearises it by automatic differentiation, forms the transfer matrix from the two manipulated variables and the two feed disturbances to the distillate composition xD and the bottoms composition xB for five control configurations under perfect and under proportional-only level control, and reduces each transfer matrix to first-order plus dead time (FOPTD) entries by least-squares fitting. Flows are in mol/s, holdups in mol, times in s, compositions are mole fractions (dimensionless) and level gains are in 1/s.

Column

The column inputs set the operating point: number of trays N (dimensionless count, 3 to 41, default 5), relative volatility α (dimensionless, default 1.5), feed flow F (in mol/s), feed composition xF (mole fraction, dimensionless), feed liquid fraction q (dimensionless), reflux flow L (in mol/s) and boilup flow V (in mol/s). Changing any input re-runs the calculation automatically once the runtime is ready; the summary table and the composition profile update. Watch xD (distillate mole fraction) and xB (bottoms mole fraction) move as N changes: more trays separate more at the same flows.

Control configuration

The Configuration select chooses which two flows are manipulated: LV manipulates the reflux flow L and the boilup flow V; DV manipulates the distillate flow D and the boilup flow V; LB manipulates the reflux flow L and the bottoms flow B; DB manipulates the distillate flow D and the bottoms flow B (all flows in mol/s); and the (L/D)-(V/B) configuration manipulates the two flow ratios (dimensionless). The Level control mode select chooses perfect level control (holdups constant) or proportional-only (P) control with reflux-drum level gain KcD (in 1/s) and reboiler level gain KcB (in 1/s). The Configuration choice changes the transfer matrix, the gains and the relative gain array in the Analysis panel; the Level control mode choice changes the poles (the dynamics), not the steady-state gains or the relative gain array; DB is the singular case (a pole at the origin).

Step test

The Step test steps one input (a manipulated variable, the feed flow F (in mol/s), or the feed composition xF (mole fraction, dimensionless)) by the Step size and plots the linear response against the nonlinear response in the App. Small steps: the two curves nearly coincide. Large steps: they separate — the separation measures the range over which the linear model can be trusted.

Steady state and composition profile

Reading the results: the summary table gives the steady state (xD (distillate mole fraction), xB (bottoms mole fraction), distillate and bottoms flows, dominant time constant in s, steady-state residual); the profile chart shows the liquid mole fraction stage by stage from the reboiler (stage 1) to the condenser (stage NT, where NT is the total number of stages, a dimensionless count). Results shown before the first live run are precomputed for the default inputs and labelled "(precomputed)"; the first live run replaces them. During a run the progress bar shows; when it finishes the bar is removed and a brief ready line remains.

Analysis

The analysis uses the column, configuration and level-mode inputs of the App tab. The gain matrix, the relative gain array (RGA) and the poles update with every run. The first-order plus dead time (FOPTD) matrix is fitted on request for the selected configuration and mode, and the channel overlay shows one fitted channel against its high-order step response.
